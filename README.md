# Retail POS Terminal & Transaction Engine

Full-stack Point of Sale (POS) workstation engineered with Python (FastAPI), SQLite, and Tailwind CSS.

## Features
- Integer-cents financial engine (8.25% TX sales tax)
- ACID-compliant SQLite checkout and inventory decrements
- Role-Based Access Control (RBAC) with 4-digit PIN lock screen
- 3-Tab Manager Console: Live Z-Report, Receipt Voiding, SKU Restock, Staff Management, and CSV Export
